# 🛡️ Toxic Comment Filtering & Classification System

## 📌 Project Overview
An advanced Natural Language Processing (NLP) project built to automatically detect and classify toxic online comments (such as insults, hate speech, threats, and obscenity). This system helps moderate online communities and platforms by flagging harmful content in real time.

## 🛠️ Tech Stack & Libraries
* **Programming Language:** Python
* **Data Manipulation:** Pandas, NumPy
* **Text Preprocessing & NLP:** NLTK / Scikit-Learn (TF-IDF Vectorizer)
* **Machine Learning Models:** Logistic Regression / Naive Bayes / Random Forest
* **Tools:** Jupyter Notebook, Git, GitHub

## 🔄 Pipeline Workflow
1. **Data Collection & Cleaning:** Ingests text datasets, removes noise, special characters, URLs, and performs stop-word removal and lemmatization.
2. **Text Vectorization:** Converts textual data into numerical matrices using TF-IDF (Term Frequency-Inverse Document Frequency).
3. **Model Training & Evaluation:** Trains classification models to predict multiple toxicity categories, evaluated using metrics like Accuracy, Precision, Recall, and F1-score.
4. **Prediction Interface:** Takes new incoming user comments and classifies them as toxic or non-toxic.
